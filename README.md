### 📊 Engagement Lifecycle

```mermaid
flowchart LR
    A[Scope & Specs] --> B[Threat Modeling]
    B --> C[Manual Line Audit]
    C --> D[PoC Exploit Build]
    D --> E[Remediation & Fix Review]
```

1. **Threat Modeling:** Map privileged roles, trust boundaries, external protocol dependencies, and critical system invariants.
2. **Deep Manual Inspection:** Rigorous line-by-line review of control flow, arithmetic constraints, state updates, and external call order.
3. **Reproducible PoCs:** All non-trivial vulnerabilities are validated with reproducible Foundry or Rust test scripts simulating the exact attack vector.
4. **Actionable Remediation:** Supplying hardened patches and alternative architectural designs rather than surface-level fixes.
